## Описание проекта
Настольное приложение на C# (Windows Forms, .NET) для генерации паролей.
Пользователь задаёт параметры (длину, используемые наборы символов),
приложение формирует пароль по заданным правилам.

## Архитектура
Приложение построено по шаблону MVC:
- Model — логика генерации пароля;
- View — формы Windows Forms;
- Controller — связывает интерфейс с моделью.
