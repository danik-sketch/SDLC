## 1. Введение

Документ фиксирует требования к десктопному генератору 8-bit звуков: синтез звука по параметрам (форма волны, эффекты), сохранение в WAV, работа с пресетами и визуализация формы волны.

### 1.1 Назначение документа

SRS определяет, **что** должна делать система, и служит основой разработки и приёмки. Детальные формулировки требований находятся в каталоге `requirements/`.

### 1.2 Область применения продукта

«Retro SFX Lab» — настольное приложение для разработчиков инди-игр. Позволяет быстро создавать ретро-звуки (прыжки, монеты, взрывы) без глубоких знаний цифровой обработки сигналов. На выходе — готовый файл WAV (PCM, 16 бит), пригодный для использования в Unity, Godot и других движках. Приложение работает локально под управлением Windows и не требует подключения к интернету. Версия 1.0 — учебная: экспорт в MP3/OGG, стерео и запись с микрофона не поддерживаются.

### 1.3 Определения и сокращения

| Term | Definition |
|------|------------|
| Bitcrush | Эффект снижения разрядности для придания «грязного» цифрового звука |
| NAudio | Библиотека .NET для работы с аудио в Windows |
| PCM | Импульсно-кодовая модуляция (несжатый звук) |
| Пресет | Готовый набор параметров для типового игрового звука |
| Seed | Начальное число генератора случайных чисел (для воспроизводимости) |
| WAV | Формат аудиофайла (RIFF/WAVE) |
| WPF | Windows Presentation Foundation (фреймворк интерфейса) |
| SRS | Software Requirements Specification |

## 2. Обзор продукта

### 2.1 Перспектива продукта

Самостоятельное настольное приложение с графическим интерфейсом. Ядро на C# выполняет синтез звука (осцилляторы, фильтры, эффекты), кодирование в WAV и сериализацию параметров. Интерфейс на WPF отображает панели настроек, график формы волны и управляет воспроизведением через NAudio. Все данные хранятся локально.

### 2.2 Функции продукта

1. Генерация звука по параметрам (5 форм волны, Slide, Vibrato, Arpeggio).
2. Обработка эффектами (Bitcrush, фильтры низких и высоких частот).
3. Работа с пресетами, случайная генерация и мутация.
4. Воспроизведение и визуализация формы волны.
5. Экспорт в WAV и сохранение/загрузка параметров в JSON.
6. Управление историей изменений (Undo/Redo).

### 2.3 Ограничения продукта

- Реализация на C# (.NET 8), интерфейс на WPF.
- Работа только под ОС Windows 10 и 11 (x64).
- Приложение полностью автономно (нет серверной части и сетевых запросов).
- Длительность генерируемого звука — не более 5 секунд.
- Экспорт только в WAV (PCM, моно, 16 бит).

### 2.4 Характеристики пользователей

- **Разработчик игры:** создаёт звуки для прототипов. Ожидает мгновенный отклик и готовые пресеты.
- **Дизайнер звука:** тонко настраивает параметры. Ожидает стабильность и воспроизводимость результата.
- **Заказчик (преподаватель):** оценивает соответствие продукта требованиям.

### 2.5 Допущения и зависимости

- На ПК пользователя установлен .NET Runtime и присутствует исправное устройство вывода звука (при его отсутствии воспроизведение блокируется, но экспорт работает).
- Одинаковые параметры синтеза и seed всегда дают побайтно идентичный файл.

### 2.6 Распределение требований

Синтез звука — `FUNC-001`; эффекты — `FUNC-002`; пресеты и рандом — `FUNC-003`; экспорт WAV — `FUNC-004`; JSON сохранение — `FUNC-005`; визуализация — `FUNC-006`; стабильность — `REL-007`, `REL-008`; скорость — `PERF-009`; язык — `CON-010`.

### 2.7 Бизнес-требования

Для определения границ функциональности продукта выделены ключевые бизнес-цели, которые преследует разработка генератора. Они отражают потребности как разработчиков игр, так и дизайнеров звука.

| ID | Бизнес-цель | Метрика успеха |
|----|-------------|----------------|
| BG-1 | Максимально ускорить получение готового звукового эффекта для прототипа | Пользователь получает и сохраняет готовый WAV-файл не более чем за 3 клика |
| BG-2 | Снизить порог входа для работы со звуком | Все параметры синтеза имеют наглядные названия и дают слышимый результат без необходимости изучать теорию ЦОС |
| BG-3 | Обеспечить бесшовную интеграцию с игровыми движками | Экспортированный WAV-файл (16 бит PCM) без ошибок импортируется в Unity и Godot |
| BG-4 | Гарантировать повторяемость и сохранность результатов | Одинаковые настройки всегда дают идентичный файл, а настройки можно сохранить в JSON |

На основе этих целей сформулированы бизнес-требования к системе (что именно она должна уметь делать для бизнеса):

| ID | Бизнес-требование | Связь с целью | Приоритет |
|----|-------------------|---------------|-----------|
| BR-01 | Библиотека готовых пресетов (прыжок, монета, взрыв) для мгновенного старта | BG-1 | Must |
| BR-02 | Гибкая панель параметров (осцилляторы, эффекты) с мгновенным визуальным и звуковым откликом | BG-2 | Must |
| BR-03 | Экспорт в стандартный формат WAV (PCM 16-bit), пригодный для геймдева | BG-3 | Must |
| BR-04 | Сохранение и загрузка параметров (сериализация в JSON) для обмена и повторного использования | BG-4 | Must |
| BR-05 | Инструменты случайной генерации и мутации для поиска неожиданных звуковых решений | BG-1, BG-2 | Should |
| BR-06 | Визуализация формы волны на графике для контроля искажений и огибающей | BG-2 | Should |

## 3. Требования

Полные формулировки и обоснования находятся в каталоге `requirements/`.

| ID | Описание требования | Критерии приёмки (Acceptance) | Верификация |
| :--- | :--- | :--- | :--- |
| **REQ-FUNC-001** | **Синтез звука:** выбор формы волны (5 типов), скважность 5–95%, частота 20–8000 Гц. | Спектр совпадает с формой; при скважности 50% доли равны; погрешность частоты ≤ 1%. | Test |
| **REQ-FUNC-002** | **Эффекты:** Slide, Vibrato, Arpeggio, фильтры НЧ/ВЧ (20–20000 Гц) и Bitcrush (1–16 бит). | Slide меняет частоту; фильтр ослабляет на 12 дБ; Bitcrush (4 бита) дает ступеньки. | Test |
| **REQ-FUNC-003** | **Пресеты и генерация:** не менее 8 пресетов, случайная генерация и мутация (в пределах ±10%). | Пресет заполняет все параметры; 1000 запусков рандома не выходят за рамки. | Test |
| **REQ-FUNC-004** | **Экспорт WAV:** PCM, моно, 16 бит, выбор частоты (11025, 22050, 44100 Гц). | Файл открывается в сторонних редакторах, параметры совпадают. | Test |
| **REQ-FUNC-005** | **Сохранение/загрузка:** сохранение текущих настроек в JSON с валидацией структуры. | Валидный файл восстанавливает звук; при ошибке JSON данные не меняются. | Test |
| **REQ-FUNC-006** | **Визуализация и Play:** отрисовка графика формы волны и воспроизведение через NAudio. | График обновляется ≤ 100 мс; Play перезапускает звук без задержек. | Test / Demo |
| **REQ-REL-007** | **Устойчивость к данным:** некорректные JSON-файлы не вызывают аварийного завершения. | При загрузке 10 битых файлов выводится ошибка, приложение работает. | Test |
| **REQ-REL-008** | **Ошибки аудио:** перехват ошибки NAudio при отсутствии устройства вывода звука. | Play неактивен, но экспорт WAV и сохранение JSON работают. | Test |
| **REQ-PERF-009** | **Скорость синтеза:** расчет 1 сек звука и экспорт 5 сек файла. | Синтез 1 с ≤ 100 мс, экспорт 5 с ≤ 500 мс. | Test |
| **REQ-CON-010** | **Платформа:** реализация на C# (.NET 8) с WPF для Windows 10/11. | Проект собирается и запускается без ошибок на целевой ОС. | Inspect / Demo |
