# Воспроизведение через NAudio, кодирование WAV собственным кодом

## Контекст и постановка задачи

SRS (REQ-FUNC-006) предусматривает воспроизведение через NAudio, а REQ-FUNC-004 — экспорт в WAV (PCM, моно, 16 бит). Вопрос: какие части аудиотракта доверить NAudio, а какие написать самим, чтобы ядро осталось независимым, а отсутствие звукового устройства не ломало экспорт?

## Драйверы решения

* Требование SRS: воспроизведение через NAudio
* Ядро не должно зависеть от NAudio (ADR-0002)
* Экспорт и сохранение должны работать без звукового устройства (REQ-REL-008)
* Совместимость WAV с Unity, Godot, Audacity (SYS-NFR-011)

## Рассмотренные варианты

* NAudio только для вывода, собственный WavWriter
* NAudio для вывода и записи (`WaveFileWriter`)
* Воспроизведение через `System.Media.SoundPlayer`

## Итог решения

Выбранный вариант: «NAudio только для вывода, собственный WavWriter», потому что это сохраняет чистоту ядра и независимость экспорта от звукового устройства.

### Последствия

* Хорошо, потому что интерфейс `IAudioPlayer` легко заменить заглушкой в тестах
* Хорошо, потому что ошибка NAudio (нет устройства) отключает только Play
* Плохо, потому что формат WAV нужно проверять в сторонних программах

### Подтверждение

Тест `WavWriterTests` проверяет заголовок и размер (441 044 байта для 5 с при 44100 Гц); ручная проверка импорта файла в Audacity, Unity и Godot (`tests/wav-export.md`); тест с заглушкой `IAudioPlayer`, имитирующей отказ устройства.

## Плюсы и минусы вариантов

### NAudio только для вывода, собственный WavWriter

* Хорошо, потому что Core без зависимостей, экспорт не зависит от устройства
* Хорошо, потому что формат WAV прост (заголовок 44 байта), легко проверить тестами
* Плохо, потому что нужно написать и протестировать запись заголовка

### NAudio для вывода и записи (`WaveFileWriter`)

* Хорошо, потому что готовый код
* Плохо, потому что Core получает зависимость от NAudio и от Windows

### Воспроизведение через `System.Media.SoundPlayer`

* Хорошо, потому что без пакетов
* Плохо, потому что нет перезапуска без задержки и не соответствует SRS

## Дополнительная информация
